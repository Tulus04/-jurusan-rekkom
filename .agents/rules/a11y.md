# Accessibility (a11y): Website Jurusan R&K

## Prinsip
Website jurusan publik HARUS bisa diakses semua orang termasuk pengguna disabilitas. Ini juga berdampak SEO positive.

Target: **WCAG 2.1 Level AA**

---

## 1. Semantic HTML

### Pakai Tag yang Benar
```html
<!-- ❌ SALAH — div soup -->
<div class="header">
    <div class="nav">
        <div class="link">Home</div>
    </div>
</div>

<!-- ✅ BENAR — semantic -->
<header>
    <nav>
        <a href="/">Beranda</a>
    </nav>
</header>
```

### Tag Wajib
- `<header>`, `<nav>`, `<main>`, `<aside>`, `<footer>`, `<article>`, `<section>`
- `<button>` untuk action, `<a>` untuk navigasi
- `<h1>` ... `<h6>` hierarki yang benar

---

## 2. Alt Text Wajib

```html
<!-- ❌ SALAH -->
<img src="foto.jpg">
<img src="foto.jpg" alt="">
<img src="foto.jpg" alt="image">

<!-- ✅ BENAR — descriptive -->
<img src="foto.jpg" alt="Mahasiswa TRPL mengikuti workshop IoT">

<!-- Decorative image (visual only, no info) -->
<img src="dekorasi.svg" alt="" role="presentation">
```

### Aturan Alt Text
- Descriptive (apa yang ada di gambar)
- Kontekstual (untuk apa di halaman ini)
- Singkat (<125 karakter)
- ❌ JANGAN "image of...", "picture of..." (redundant)
- ❌ JANGAN nama file ("IMG_1234.jpg")

---

## 3. Keyboard Navigation

### Wajib Bisa Diakses Tab
- Semua link `<a>` & button `<button>`
- Form input (input, textarea, select)
- Toggle/dropdown (carousel, modal, accordion)

### Focus Visible
```css
/* JANGAN hapus outline tanpa replace! */
*:focus-visible {
    outline: 2px solid var(--bs-primary);
    outline-offset: 2px;
}

/* ❌ SALAH — bikin user keyboard tersesat */
*:focus { outline: none; }
```

### Skip to Content (Bonus)
```html
<a href="#main-content" class="visually-hidden-focusable">
    Lewati ke konten utama
</a>
```

## 4. Form Accessibility

### Label Wajib
```html
<!-- ❌ SALAH -->
<input type="email" placeholder="Email">

<!-- ✅ BENAR -->
<label for="email">Alamat Email</label>
<input type="email" id="email" name="email">

<!-- Atau wrapping -->
<label>
    Alamat Email
    <input type="email" name="email">
</label>
```

### Required & Error
```html
<label for="judul">
    Judul Berita <span class="text-danger" aria-label="wajib">*</span>
</label>
<input type="text" id="judul" name="judul" required 
       aria-required="true"
       aria-describedby="judul-error">
@error('judul')
    <div id="judul-error" class="invalid-feedback" role="alert">
        {{ $message }}
    </div>
@enderror
```

## 5. ARIA (Pakai Hemat)

### Prinsip
**Semantic HTML > ARIA**. Pakai ARIA hanya kalau native HTML tidak cukup.

### ARIA yang Berguna
```html
<!-- Icon button (tanpa visible text) -->
<button aria-label="Tutup">
    <i class="bi bi-x"></i>
</button>

<!-- Loading indicator -->
<div role="status" aria-live="polite">Memuat data...</div>

<!-- Tab panel -->
<button role="tab" aria-selected="true" aria-controls="panel-1">Tab 1</button>
<div id="panel-1" role="tabpanel">...</div>

<!-- Alert (pesan penting) -->
<div role="alert">Berita berhasil disimpan.</div>
```

## 6. Color Contrast

### Target WCAG AA
- Body text: 4.5:1
- Large text (>18pt): 3:1
- UI components: 3:1

### ❌ SALAH (di project ini, sudah ditemukan)
```css
.breadcrumb-disabled {
    color: rgba(255, 255, 255, 0.65);  /* invisible di bg light */
}
```

### ✅ BENAR
```css
.breadcrumb-disabled {
    color: #6c757d;  /* contrast 4.6:1 di white bg */
}
```

### Tools Cek Contrast
- Chrome DevTools (built-in)
- WebAIM Contrast Checker: https://webaim.org/resources/contrastchecker/
- Lighthouse audit

## 9. Modal & Dialog

### Bootstrap Modal sudah punya ARIA bawaan, JANGAN dirusak:
```html
<div class="modal" tabindex="-1" 
     role="dialog" 
     aria-labelledby="modal-title"
     aria-modal="true">
    <div class="modal-dialog">
        <div class="modal-content">
            <h5 id="modal-title" class="modal-title">Konfirmasi Hapus</h5>
            ...
        </div>
    </div>
</div>
```

## 10. Tools Audit

### Otomatis
- **Lighthouse** (Chrome DevTools) — target a11y score >90
- **axe DevTools** — extension Chrome/Firefox
- **WAVE** — https://wave.webaim.org

### Manual
- Test pakai keyboard saja (no mouse)
- Test pakai screen reader (NVDA Windows, VoiceOver Mac)
- Resize text 200% — masih readable?

---

## 11. Larangan

- ❌ JANGAN `outline: none` tanpa replacement focus indicator
- ❌ JANGAN gunakan warna saja sebagai indikator (pakai icon + text)
- ❌ JANGAN auto-play audio/video
- ❌ JANGAN flash >3x per detik (rawan epilepsi)
- ❌ JANGAN form input tanpa label (placeholder bukan pengganti label)
- ❌ JANGAN trap keyboard di komponen (escape harus selalu work)
